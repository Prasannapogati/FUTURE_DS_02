# Customer Retention & Churn Analysis
## Project Overview
This project analyzes customer churn and retention using Power BI and the Telco Customer Churn dataset.
## Objectives
- Analyze customer churn and retention rates.
- Identify customer segments with high churn.
- Understand the relationship between customer tenure and churn.
- Recommend strategies to improve customer retention.
## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- GitHub
## Dashboard KPIs
- Total Customers
- Churned Customers
- Churn Rate
- Retention Rate

## Key Insights
- Month-to-month contract customers have the highest churn count.
- Customers with shorter tenure show higher churn counts.
- Fiber optic customers contribute to a high number of churned customers.

## Recommendations
- Offer loyalty benefits and suitable discounts.
- Improve onboarding for new customers.
- Monitor customer satisfaction and service quality.
- Contact customers who may be likely to leave.

## Deliverables
- Power BI dashboard
- Business insights and recommendations
- Dashboard screenshots
